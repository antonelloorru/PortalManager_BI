# MANUALE UTENTE — v1.10.12

## Report (Service Desk, Service SOC, Attività & Rendicontazione DGB)
1. Impostare il **filtro principale** (pannello «Filtri»): è l'unico che conta per pagina, export e report.
2. Barra **Report generale**: DOCX · XLSX · CSV · PDF.
3. **Report singoli per componente / incaricato** (sotto la barra, quando non si è filtrato un tecnico): una riga per risorsa con i quattro formati; «Tutti (ZIP)» scarica un file per risorsa.
4. Con un tecnico selezionato nel filtro, la barra diventa «Report del … selezionato».

| Formato | Contenuto |
|---|---|
| DOCX / PDF | documento impaginato: filtri, indicatori, tabelle, grafici; elenchi fino a 1.000 righe |
| XLSX | foglio «Riepilogo» (filtri e indicatori) + un foglio per tabella, valori numerici |
| CSV | tutte le sezioni in un file (`;`, apribile in Excel) |

## DGB › Anomalie orarie
Il blocco filtri proprio è stato rimosso: periodo, incaricato e contratto si impostano nel filtro principale (visibile anche in questa scheda). Tipo e severità sono nel riepilogo e nelle colonne.
