# Manuale Utente — Anagrafica dipendenti (v1.8.43)

## Esportare l'elenco completo

Premendo **Esporta** compare in cima al menu la casella **"Tutti i record (ignora
i filtri)"**.

Se la lasciate vuota scaricate esattamente quello che state vedendo, filtri
compresi: è il comportamento di sempre. Se la spuntate scaricate l'elenco
completo, anche se in quel momento avete dei filtri attivi. Il nome del file
finisce con `_completo`, così riconoscete a colpo d'occhio quale dei due avete
scaricato.

La scelta vale per tutti i formati: CSV, Excel, PDF e Word.

## Il modello per l'import

Nella pagina **Import dipendenti XLSX** trovate due pulsanti per scaricare il
modello, in Excel o in CSV. Il modello contiene tutte le colonne dell'anagrafica,
già intestate, più una riga di esempio da sostituire con i vostri dati.

Il file Excel ha un secondo foglio, **Istruzioni**, che per ogni colonna spiega
cosa inserire e in che formato.

## Come compilarlo

Sostituite la riga di esempio con i vostri dati, una riga per persona.

Solo **Cognome** e **Nome** vanno compilati sempre. Tutte le altre colonne possono
restare vuote: non è necessario riempire tutto.

Non rinominate e non riordinate le intestazioni: il portale le riconosce per
nome. Le colonne che non vi servono potete lasciarle vuote oppure eliminarle.

Le date si scrivono nella forma `15/03/2020`.

## Aggiornare persone già presenti

Se nel file inserite il codice fiscale di qualcuno già in anagrafica, i suoi dati
vengono aggiornati anziché creare un doppione.

Le celle lasciate vuote **non** cancellano quello che c'è già. Per correggere solo
un dato, per esempio il livello, compilate codice fiscale, cognome, nome e
livello, lasciando vuoto tutto il resto.

## Prima di caricare tanti record

Provate con una riga sola: caricate il file, controllate l'anteprima e confermate.
Verificate in anagrafica che il risultato sia quello atteso, poi procedete con
l'elenco completo.

## Se usate un file vecchio

I file preparati con i modelli precedenti funzionano ancora: il portale riconosce
anche le vecchie intestazioni. Non dovete rifarli.
