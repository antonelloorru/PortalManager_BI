# MANUALE AMMINISTRATORE — v1.10.23

1. WordPress › Plugin › Carica plugin → `pm-ats-1.3.4.zip` → Sostituisci. Svuotare la cache del sito e lo «Static CSS» di Divi.
2. *Lavora con noi › Impostazioni › Aspetto › Sezione di testata*:
   - spuntare «Mostra la testata…» e indicare il titolo;
   - **Scegli dalla Libreria media** → «Carica file» oppure scegliere un'immagine esistente → «Usa questa immagine». Consigliata un'immagine larga almeno 1920 px, rapporto circa 3:1;
   - modalità «Immagine intera» (nessun ritaglio) oppure «Fascia proporzionale, immagine ritagliata»;
   - «Rimuovi» toglie l'immagine; si può ancora incollare un URL esterno, che però non avrà le dimensioni ridotte automatiche.
3. Salva. La testata si adatta a desktop, tablet e telefono.
4. In fondo alle impostazioni e nel piè di pagina compaiono i riferimenti di creazione del plugin.
