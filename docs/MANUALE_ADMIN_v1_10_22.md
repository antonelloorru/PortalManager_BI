# MANUALE AMMINISTRATORE — v1.10.22

1. WordPress › Plugin › Carica plugin → `pm-ats-1.3.3.zip` → Sostituisci. Svuotare la cache del sito (e lo «Static CSS» di Divi).
2. *Lavora con noi › Impostazioni › Aspetto › Titolo della pagina*:
   - «Nascondi il titolo» → scompare la scritta «Lavora con noi» stampata dal tema sopra il contenuto (resa come l'esempio, che ha già la testata «Lavora con Noi»);
   - «Mostra un testo personalizzato» + testo → l'h1 mostra il testo indicato;
   - «Mostra il titolo della pagina (tema)» → comportamento precedente.
3. Il titolo della scheda di ogni posizione, il titolo nella scheda del browser e i menu non cambiano. Per cambiare anche il `<title>` modificare il titolo della pagina in WordPress o nel plugin SEO.
