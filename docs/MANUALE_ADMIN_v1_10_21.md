# MANUALE AMMINISTRATORE — v1.10.21

1. WordPress › Plugin › Carica plugin → `pm-ats-1.3.2.zip` → Sostituisci. Svuotare la cache del sito (e lo «Static CSS» di Divi, se attivo).
2. Le pagine delle posizioni e «Lavora con noi» non mostrano più la colonna «Articoli recenti» di Divi. Per ripristinarla: *Lavora con noi › Impostazioni › Aspetto › Barra laterale del tema*.
3. Per avere all'attivazione la stessa resa dell'esempio:
   - *Aspetto › Elenco* = «Lavora con noi: elenco posizioni e modulo a destra» (predefinito);
   - *Elenco posizioni* = «Titolo cliccabile»;
   - *Barra laterale del tema* = nascosta (predefinito);
   - nella pagina «Lavora con noi», riga Divi a **una colonna** con `[pm_ats_lavora_con_noi hero="0"]`.
