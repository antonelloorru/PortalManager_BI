# Manuale Utente — v1.8.56

## Filtrare le anomalie orarie

Nella sezione **Anomalie orarie** c'è ora un riquadro **Filtri**. Potete cercare
per:

- **Tecnico** — basta scrivere una parte del nome; il campo suggerisce i
  nominativi presenti
- **Tipo di anomalia**
- **Severità** — alta o media
- **Dal giorno / Al giorno**

I filtri si combinano fra loro. Accanto al pulsante **Applica** è scritto quante
segnalazioni corrispondono.

Il pulsante **Azzera** rimuove tutti i filtri e compare solo quando ce n'è almeno
uno attivo.

## Scaricare l'elenco

**Esporta XLSX** per Excel, **Esporta CSV** per un file di testo. Il file contiene
le stesse colonne che vedete sullo schermo e rispetta i filtri impostati.

Una cosa da sapere: a video l'elenco si ferma a 500 righe per non rallentare la
pagina, mentre **il file scaricato le contiene tutte**.

Lo vedete scritto sopra la tabella: se c'è *«500 di 546 righe»*, il file avrà 546
righe. È corretto così.

## I riquadri colorati in alto

Cliccandone uno, l'elenco mostra solo quel tipo di anomalia. Gli altri filtri che
avevate impostato — tecnico, date — restano attivi.
