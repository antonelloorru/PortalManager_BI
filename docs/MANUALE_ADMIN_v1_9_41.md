# Manuale Amministratore — v1.9.41

## Riepilogo per Codice Contratto (ripristinato)
In fondo alla Relazione di Servizio IT è di nuovo presente il riepilogo per **Codice
Contratto** con il **dettaglio per commessa**: per ogni contratto una riga di
sottototale e, sotto, le sue commesse con area tecnologica, interventi, giorni-uomo,
ore, ore extra e produzione teorica a listino. Rispetta i filtri di periodo/tecnico/
contratto impostati in alto.
