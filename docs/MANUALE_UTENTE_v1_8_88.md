# Manuale Utente — v1.8.88

## La scheda ora filtra tutta la pagina

Cliccando sul nome di un componente, **tutti i riquadri** — indicatori, gestione
dei ticket, andamento, tabelle — si riferiscono a quella persona.

Prima alcuni mostravano ancora i dati di tutti, e potevano essere scambiati per
suoi.

Il pulsante **Chiudi scheda** riporta alla vista d'insieme.

## Stampare un report

Fra i pulsanti dei filtri trovate:

- **Report personale** quando è aperta la scheda di un componente
- **Report generale** altrimenti

Si apre una pagina pronta per la stampa, senza menu, con il pulsante *Stampa* in
alto a destra.

Per stampare anche i colori delle barre, attivate **«Grafica di sfondo»** nelle
opzioni di stampa del browser.

## Scaricare i dati

Il pulsante **XLSX** scarica quello che vedete. Con un componente selezionato il
file contiene anche la sua scheda, i contratti, le code e l'elenco dei ticket
presi in carico.
